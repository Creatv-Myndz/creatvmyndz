# OAZIS — produced audio

Drop produced music beds here and the app uses them automatically
(the generated pad drops to ~18% underneath; rain, binaural/frequency layer and "Depth" stay live in code).

| File | World | Brief |
|---|---|---|
| `create.mp3` | CREATE · θ 7 Hz | warm, open, curious; soft keys + light textures, no drums |
| `flow.mp3`   | FLOW · β 16 Hz  | steady, minimal pulse, low and even, nothing to "follow" |
| `dream.mp3`  | DREAM · θ 5 Hz  | floating pads, long reverbs, pale blue, no rhythm |
| `calm.mp3`   | CALM · α 10 Hz  | slow tide, warm low strings / pads |
| `sleep.mp3`  | SLEEP · δ 2 Hz  | very low, very slow, almost nothing (rain is added in code) |
| `awaken.mp3` | AWAKEN · α 12 Hz| bright, rising, morning light |

Specs: instrumental, 3–6 min, 44.1 kHz, MP3 256 kbps (or AAC), around −18 LUFS, no fade in/out,
key-stable (no big changes) — the app crossfades the end into the start (5 s) so it loops endlessly.
Make sure the license allows commercial use in a paid app (e.g. Suno Pro/Premier, ElevenLabs Music, Stable Audio).
